How Shortlink serves a click

example · Oct 10, 2026

The edge answers 94% of clicks from its cache. Only a cache miss reaches Postgres.

A click reaches Postgres only when the edge cache misses.

The edge sends each click to the queue after it answers, so the count never slows the redirect.

Only the Links API writes to Postgres.

Redirects keep working when Postgres, the queue or KV is down.

Cloudflare KV is the best store for the link cache.

At a 94% hit rate, the average redirect takes 7.1 ms.

A new link reaches every edge within 60 seconds.

GET /:id carries 99% of all requests.
